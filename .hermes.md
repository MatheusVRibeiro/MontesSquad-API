## Contrato da API

- Respostas padronizadas `{sucesso, message, dados}` (+ `nItens` em listagens); erros via `AppError` + middleware global
- ⚠️ **EXCEÇÃO**: `POST /login` retorna `{sucesso, message, token, dados}` — o token fica na RAIZ (`json.token`), NÃO dentro de `dados`
- **Públicas**: `POST /login`, `/recuperar-senha`, `/resetar-senha`, `POST /usuarios`, `POST /github/webhook` (auth = assinatura HMAC), `GET /github/callback`
- **Autenticadas**: `/usuarios` (GET/PATCH/DELETE), `GET /usuarios/me`, `/projetos` (CRUD), `/habilidades*`, `/projetos/:id/{mensagens,candidaturas,membros,tarefas}`, `/notificacoes`, `/notificacoes/ler-tudo`, `/usuarios/:id/reputacao`, rotas GitHub (`/github/me`, `/github/connect`, `/github/disconnect`, `/projetos/:id/github/repository|status`)
- Backend devolve **camelCase** nos controllers (ex.: notificações `{id, type, title, description, createdAt, read, link}`) — conferir shape real com curl antes de tipar no frontend
